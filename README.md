Arcade 1990

Projeto em C para organizar um fliperama, com módulos para jogadores, máquinas, venda de fichas e pontuações. No momento, os menus estão criados, mas as operações exibem mensagens de “Em construção”.

Responsabilidades:

    Leonardo Portes Silveira: gestão de jogadores — cadastro, listagem, atualização e desativação.
    Guilherme Barbosa Ferreira Chagas: catálogo de máquinas — cadastro, listagem, atualização do status de manutenção e remoção.
    William dos Santos Oliveira: caixa e venda de fichas — vendas, histórico, estornos e relatório de faturamento.
    Hyan Nascimento: high scores e relatórios — registro de pontuações, ranking e análises.
